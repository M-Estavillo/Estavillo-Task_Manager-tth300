# Task Manager - Mini Information System

A simple task management web system built with vanilla HTML/CSS/JavaScript, an Express API, and a MySQL database.

## Features

- Create tasks with title, description, status, priority, and due date
- View dashboard task statistics
- View, filter, and sort all tasks
- Edit existing tasks
- Mark tasks as complete
- Delete tasks
- Store task data in MySQL

## Database Setup

The backend does not automatically create the database. Create it manually and import the SQL file through phpMyAdmin.

1. Start Apache and MySQL in XAMPP/MAMP.
2. Open phpMyAdmin:

```txt
http://localhost/phpmyadmin
```

3. Create a database named:

```txt
task_manager_db
```

4. Select the `task_manager_db` database.
5. Click the `Import` tab.
6. Choose this file:

```txt
task_manager_db.sql
```

7. Click `Go`.

After importing, the database should contain a `tasks` table.

## Run The App

Install dependencies inside this folder:

```bash
npm install
```

Start the backend server:

```bash
npm start
```

Open the app:

```txt
http://localhost:3000
```

## MySQL Connection

The backend uses this local MySQL connection in `server.js`:

```js
const db = mysql.createConnection({
    host: "localhost",
    user: "root",
    password: "",
    database: "task_manager_db"
});
```

If your local MySQL password is different, update the `password` value in `server.js`.

## API Routes

```txt
GET    /api/tasks        # Get all tasks
GET    /api/tasks/:id    # Get one task
POST   /api/tasks        # Create task
PUT    /api/tasks/:id    # Update task
DELETE /api/tasks/:id    # Delete task
```

## Task Fields

- `title` required
- `description` optional
- `status` values: `To Do`, `In Progress`, `Done`
- `priority` values: `Low`, `Medium`, `High`
- `dueDate` optional
- `createdAt` generated by MySQL
